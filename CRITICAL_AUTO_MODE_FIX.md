# КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ: Сброс состояния игры в авторежиме

## Критическая ошибка

**Проблема**: Авторежим не сбрасывал состояние игры при возврате к экрану ввода имени. Это приводило к тому, что в следующем авторежиме игра запускалась без кубиков (все кубики уже были уничтожены в предыдущей игре).

**Шаги для воспроизведения**:
1. Авторежим закончил игру (победа или поражение)
2. Нажать Enter (показать результаты)
3. Нажать 0 (запустить авторежим снова)
4. **ОШИБКА**: Игра запускается без кубиков

## Корневая причина

Состояние игры (кубики, мяч, платформа, очки, жизни) не сбрасывалось при возврате к экрану ввода имени в авторежиме. Все переменные сохраняли состояние от предыдущей игры.

## КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ

### 1. Полный сброс состояния в начале каждого цикла

```python
while True:  # Внешний цикл для возврата к вводу имени в авторежиме
    # Сбрасываем флаг завершения авторежима для каждого нового запуска
    auto_mode_complete = False
    running = True  # Всегда начинаем с флага running=True
    
    # ПОЛНЫЙ СБРОС СОСТОЯНИЯ ИГРЫ ПРИ КАЖДОМ НОВОМ ЗАПУСКЕ
    paddle = Paddle()
    ball = Ball()
    ball_speed = settings_manager.get_ball_speed()
    ball.set_speed(ball_speed)
    ball.reset(paddle.rect)
    ball.vel_y = 0
    bricks = build_bricks()
    score = 0
    lives_left = MAX_LIVES
    game_over = False
    game_started = False
    
    # Пересоздаем AI-систему при каждом новом запуске (для корректной работы авторежима)
    ai_player = AIPlayer(SCREEN_WIDTH, SCREEN_HEIGHT, debug_mode=True)
```

### 2. Удаление дублирующей инициализации

Удалена избыточная инициализация объектов игры в начале функции `main()`, поскольку теперь состояние сбрасывается в начале каждого цикла.

### 3. Упрощение логики перезапуска

Поскольку состояние игры уже сброшено в начале каждого цикла, логика перезапуска в игровом цикле упрощена:

```python
if restart_game:
    if auto_mode:
        # В авторежиме возвращаемся к вводу имени
        auto_mode_complete = True
        running = False
        break
    else:
        # В ручном режиме перезапускаем игру
        # Состояние уже сброшено в начале цикла, только пересоздаем AI
        ai_player = AIPlayer(SCREEN_WIDTH, SCREEN_HEIGHT, debug_mode=False)
        ai_player.activate()
```

## Что сбрасывается при каждом новом запуске

1. **Платформа** (`paddle = Paddle()`) - новая позиция платформы
2. **Мяч** (`ball = Ball()`) - новая позиция и скорость мяча
3. **Кубики** (`bricks = build_bricks()`) - полный набор кубиков
4. **Очки** (`score = 0`) - сброс счетчика очков
5. **Жизни** (`lives_left = MAX_LIVES`) - восстановление всех жизней
6. **Состояние игры** (`game_over = False`, `game_started = False`) - сброс флагов
7. **AI система** - пересоздание AI-системы для корректного обучения
