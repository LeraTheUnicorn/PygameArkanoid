### 2. Модуль `ai/strategy/` (стратегии движения)

#### `paddle_movement.py` - Основная логика движения платформы

**Класс:** `PaddleMovementStrategy`

**Метод для разделения:**
- `move_paddle_towards()` - **1166 строк** - основной метод движения

**Логические блоки для разделения:**

1. **Проверка состояния** (строки 3030-3061)
   - Метод: `_validate_state() -> bool`
   - Проверка `current_game_state` и `is_active`
   - Обработка `ball_vel_y == 0`

2. **Обработка зоны кубиков** (строки 3063-3079)
   - Метод: `_handle_bricks_zone_movement() -> Optional[int]`
   - Проверка `ball_y < separation_zone_start`
   - Исключение для последнего кирпича

3. **Обработка потерянного мяча** (строки 3081-3092)
   - Метод: `_handle_lost_ball() -> Optional[int]`
   - Проверка `ball_y > paddle_y`

4. **Обработка зоны разделения** (строки 3094-3320)
   - Метод: `_handle_separation_zone() -> Optional[int]`
   - Обнаружение отскоков от кирпичей
   - Логирование состояния

5. **Фиксация целевой позиции** (строки 3149-3802)
   - Метод: `_handle_fixed_target() -> Optional[int]`
   - Проверка отскоков от стены
   - Движение к зафиксированной позиции
   - Обработка EDGE зон

6. **Установка новой цели** (строки 3809-3941)
   - Метод: `_set_new_target() -> Optional[int]`
   - Расчет оптимальной позиции
   - Проверка достижимости цели
   - Установка целевой позиции

7. **Обычная логика движения** (строки 3943-4173)
   - Метод: `_handle_normal_movement() -> int`
   - Расчет оптимальной позиции
   - Проверка зацикливания
   - Адаптивная скорость
   - Плавность движения

**Дополнительные методы:**
- `_fallback_movement()` (~60 строк) - резервное движение
- `_detect_loop_pattern()` (~50 строк) - обнаружение зацикливания
- `_change_strategy_if_looping()` (~25 строк) - смена стратегии

**Зависимости:**
