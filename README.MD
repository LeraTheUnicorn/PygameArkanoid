# 🕹️ Игра Арканоид с AI-системой

Классическая игра Арканоид, написанная на Python с использованием Pygame. Включает в себя систему рекордов, звуковые эффекты и современный интерфейс.

## 🎮 Особенности

### Геймплей

- **Классический геймплей Арканоид** - отбивайте мяч платформой и разрушайте кубики

## 🚀 Установка и запуск

### Зависимости

Для работы игры требуются следующие библиотеки Python:
- **pygame** (2.5.2+) - для создания игр
- **numpy** (2.1.0+) - для математических вычислений
- **scikit-learn** (1.7.2+) - для машинного обучения (кластеризация и классификация)

### Автоматическая установка (Windows)

1. Запустите файл `install_dependencies.bat`
2. Дождитесь завершения установки всех зависимостей
3. Запустите игру: `python PyGameBall.py`

### Ручная установка

```bash
python -m pip install --upgrade pip
python -m pip install pygame numpy scikit-learn
```

### Использование Poetry (рекомендуется)

Проект использует Poetry для управления зависимостями. Убедитесь, что Poetry установлен:

```bash
pip install poetry
poetry install
poetry run python PyGameBall.py
```

## 🏗️ Архитектура проекта

Проект использует современную архитектуру с разделением ответственности:

### MVC (Model-View-Controller) паттерн

- **Models** (`game_models.py`) - игровые объекты и состояние:
  - `Ball` - модель мяча
  - `Paddle` - модель платформы
  - `GameState` - состояние игры

- **Views** (`game_views.py`) - представления для отрисовки:
  - `BricksView` - отрисовка кирпичей
  - `PaddleView` - отрисовка платформы
  - `BallView` - отрисовка мяча
  - `HUDView` - отрисовка интерфейса

- **Controllers** (`game_controllers.py`) - игровая логика:
  - `GameController` - основная игровая логика
  - `InputController` - обработка пользовательского ввода

### Оптимизация производительности

- **Dirty Rects** (`dirty_rects.py`) - система оптимизации отрисовки:
  - Перерисовывает только измененные области экрана
  - Значительно улучшает производительность на слабых устройствах
  - Автоматически объединяет перекрывающиеся области

### Dependency Injection

- **DI Container** (`di_container.py`) - управление зависимостями:
  - Централизованное создание объектов
  - Упрощает тестирование (легко подменять зависимости)
  - Улучшает поддерживаемость кода

### Централизованная конфигурация

- **Game Config** (`game_config.py`) - все константы в одном месте:
  - Размеры экрана, скорости, цвета
  - Легко изменять настройки игры
  - Улучшает читаемость кода

Подробнее о миграции на новую архитектуру см. [ARCHITECTURE_MIGRATION.md](ARCHITECTURE_MIGRATION.md)

## 🤖 ИИ-система (Machine Learning)

- **Авторежим игры** - нажмите "0" для запуска интеллектуального авторежима с именем "robot"
- **Режим обучения (Training Mode)** - нажмите "8" для запуска режима непрерывного обучения ИИ
- **Предсказание траектории** - ИИ точно предсказывает траекторию мяча с учетом отскоков от стен
- **Машинное обучение** - система учится на каждом действии и улучшает производительность
- **Визуальная отладка** - отображение предсказанной траектории и оптимальных позиций
- **Система аналитики** - подробная статистика производительности ИИ с сохранением в JSON
- **Интеллектуальное управление** - оптимальное позиционирование платформы для максимальной эффективности
- **Совместное использование данных обучения** - результаты обучения из режима 8 (Training Mode) автоматически используются в режиме 0 (Авторежим). Все обученные модели, стратегии и паттерны сохраняются и загружаются автоматически между сессиями.

### Режим обучения (Training Mode) - Клавиша "8"

**Особенности режима обучения:**

- **Непрерывная игра** - ИИ играет бесконечно до нажатия ESC или закрытия окна
- **Адаптивное обучение** - ИИ автоматически оптимизирует скорость мяча и платформы на основе эффективности
- **3 жизни** - стандартное количество жизней для оценки эффективности обучения
- **Динамическая адаптация** - скорость мяча и платформы изменяются во время игры на основе результатов
- **Метрики обучения** - отображение прогресса обучения (Learning), точности (Accuracy) и статистики игр
- **Автоматический перезапуск** - игра автоматически перезапускается после завершения уровня или потери всех жизней
- **Оптимизация параметров** - ИИ учится находить оптимальные значения скорости мяча и платформы для максимальной эффективности

**Как работает обучение:**

1. ИИ начинает с базовых параметров скорости
2. После каждого матча анализирует эффективность (кубики/время/жизни)
3. Адаптирует скорость мяча и платформы для улучшения результатов
4. Сохраняет данные обучения для использования в будущих сессиях

**Выход из режима обучения:**

- Нажмите **ESC** для завершения обучения и просмотра статистики
- Закройте окно игры для завершения с сохранением данных обучения

### Архитектура AI

В проекте используется **комплексная система машинного обучения**, основанная на **проприетарном Reinforcement Learning (RL) алгоритме** и **физических моделях предсказания траекторий**.

**Основные компоненты:**

1. **AIPlayer** - главный оркестратор системы
1. **TrajectoryPredictor** - предсказание траекторий мяча
1. **PositionOptimizer** - оптимизация позиции
1. **LearningSystem** - система обучения с подкреплением
1. **PerformanceLogger** - логирование и анализ производительности

### Алгоритм машинного обучения

**Тип модели:**

- **Custom Reinforcement Learning** (обучение с подкреплением)
- **Проприетарная реализация** на основе эвристического подхода
- **Использует scikit-learn** для кластеризации траекторий (KMeans) и классификации (RandomForestClassifier)
- **НЕ использует** TensorFlow или PyTorch

**Ключевые особенности:**

- Адаптивные веса стратегий: `aggressive`, `conservative`, `precision`, `speed`
- Анализ паттернов траекторий с квантованием координат
- Система предотвращения зацикливания (loop prevention)
- Обучение на основе успешности действий

**Авторежим (клавиша "0"):**

1. **Запустите игру**
1. **Нажмите "0"** для активации авторежима
1. **AI автоматически примет управление** под именем "robot"
1. **Использует результаты обучения** - AI автоматически загружает и использует все данные обучения из режима 8 (Training Mode), включая обученные модели, стратегии и паттерны
1. **Для отладки:** включите debug режим в настройках для визуализации

**Режим обучения (клавиша "8"):**

1. **Запустите игру**
1. **Нажмите "8"** для активации режима обучения
1. **AI автоматически начнет обучение** под именем "training"
1. **Игра будет продолжаться бесконечно** до нажатия ESC
1. **AI будет адаптировать параметры** скорости мяча и платформы во время игры
1. **Для выхода:** нажмите ESC для просмотра статистики обучения

### Сравнение режимов 0 и 8

| Параметр | Режим 0 (Авторежим) | Режим 8 (Training Mode) |
|----------|---------------------|-------------------------|
| **Активация** | Клавиша "0" | Клавиша "8" |
| **Имя игрока** | "robot" | "training" |
| **Продолжительность** | Одна игра | Бесконечная |
| **Экран результатов** | Показывается | Не показывается |
| **Скорость мяча** | Фиксированная (настраивается вручную через ↑/↓) | Динамическая (15-50, адаптируется ИИ каждую секунду) |
| **Скорость платформы** | Адаптивная (минимум 13.5) | Управляется ИИ (множитель 0.5-10.0) |
| **Обучение** | Пассивное (учится на действиях) | Активное (адаптирует параметры после каждого матча) |
| **Использование данных** | Использует обученные модели | Создает и сохраняет модели |
| **Перезапуск** | Вручную через экран результатов | Автоматически |
| **Метрики в HUD** | Базовая информация | Расширенная (Learning, Games, Best time) |
| **Выход** | Через экран результатов | Только ESC (с выводом статистики в консоль) |

**Основные различия:**

- **Режим 0 (Авторежим)** - это "боевой режим", где ИИ использует накопленные знания для игры. Идеально подходит для демонстрации работы ИИ или тестирования обученных моделей. ИИ учится на действиях, но не изменяет параметры скорости во время игры.

- **Режим 8 (Training Mode)** - это "тренировочный полигон" для ИИ, где он учится и оптимизирует параметры. ИИ активно адаптирует скорость мяча и платформы на основе эффективности игры. Все обученные модели сохраняются и автоматически используются в режиме 0.

**Общее:**

- Оба режима используют одну и ту же систему ИИ (`AIPlayer`)
- Оба режима сохраняют данные обучения в `ai/models/ai_model.json`
- Режим 0 использует результаты обучения из режима 8
- Оба режима используют одинаковые алгоритмы прицеливания и предсказания траекторий

**Рекомендации по использованию:**

- **Режим 0**: Используйте для демонстрации работы ИИ или тестирования обученных моделей
- **Режим 8**: Используйте для обучения и оптимизации параметров ИИ перед использованием в режиме 0

### 😡 Подробное объяснение работы ИИ-системы

#### 1) Предсказание траектории ИИ с учетом отскоков от стен

**Что это:** Система как шахматист, которая просчитывает несколько ходов вперед.

**Как работает:**

- ИИ анализирует текущую позицию мяча, его скорость и направление
- Создает виртуальную "симуляцию" движения мяча на 50 точек вперед
- При каждом "шаге" проверяет: если мяч ударяется о стену → меняет направление на противоположное
- Так продолжается до тех пор, пока мяч не достигнет низа экрана или платформы
- В результате ИИ точно знает, куда прилетит мяч, и может заранее подготовиться

**Простыми словами:** ИИ говорит себе: "Мяч сейчас летит туда, через 2 секунды он отскочит от правой стены, полетит влево, затем вверх, и приземлится именно здесь!" И заранее ставит платформу в нужное место.

#### 2) Машинное обучение - система учится на каждом действии и улучшает производительность

**Что это:** ИИ как студент, который становится умнее после каждого урока.

**Как работает:**

- После каждого действия ИИ записывает: "Что я сделал? Получилось ли? Насколько уверен я был?"
- Если действие было успешным → ИИ запоминает: "Эта стратегия работает хорошо!"
- Если провал → запоминает: "Этот подход неэффективен"
- Система "подстраивает" свою стратегию: больше использует успешные приемы, меньше - неудачные
- Запоминает, в каких позициях платформы чаще возникают успешные ситуации

**Простыми словами:** Сначала ИИ играет как новичок, иногда промахивается. Но после каждой игры он анализирует: "Ага, когда я двигал платформу резко влево и быстро, мяч попадал в кубики лучше! Буду так делать чаще!"

#### 3) Система аналитики - подробная статистика производительности ИИ

**Что это:** Подробный дневник всех действий ИИ для анализа прогресса.

**Как работает:**

- Записывает КАЖДОЕ действие: движение платформы, предсказания траектории, попадания в кубики
- Сохраняет время, расстояния, точность предсказаний, результаты игр
- Создает отчеты: "Из 10 игр выиграно 7" или "Средняя точность предсказаний 85%"
- Анализирует тренды: улучшается ли игра со временем
- Хранит историю всех сессий для долгосрочного анализа

**Простыми словами:** Система ведет подробную статистику: "Сегодня ИИ сделал 247 движений платформой, попал в кубики 89 раз из 100 попыток, играл 15 минут. По сравнению со вчерашним днем точность улучшилась на 5%!"

#### 4) Интеллектуальное управление - оптимальное позиционирование платформы для максимальной эффективности

**Что это:** ИИ как опытный игрок, который всегда знает лучшую позицию для платформы.

**Как работает:**

- Если мяч летит вниз → использует предсказание траектории для точного позиционирования
- Если мяч летит вверх → предсказывает его будущее движение и готовится
- Анализирует расположение всех кубиков и находит оптимальную позицию, с которой можно попасть в больше всего кубиков
- Учитывает вес кубиков (верхние сложнее достать → получают больший приоритет)
- Если не может найти идеальную позицию → использует резервные стратегии

**Простыми словами:** ИИ не просто ловит мяч - он думает стратегически: "Если я поставлю платформу здесь, то после отскока мяч полетит именно в те кубики, которые сложнее всего достать, и потом вернется обратно ко мне!" Это как играть в бильярд, где нужно загнать шар в лузу за несколько ходов.
