# Инструкция по установке и запуску игры Арканоид

## Требования
- Python 3.8 или выше
- pip (менеджер пакетов Python)

## Установка зависимостей

Перед запуском игры необходимо установить все необходимые зависимости:

```bash
pip install -r requirements.txt
```

Или установить пакеты по отдельности:

```bash
pip install pygame>=2.5.2
pip install numpy>=2.1.0
pip install pytest>=7.0.0
```

## Запуск игры

### Из корневой папки проекта:
```bash
python src/game/PyGameBall.py
```

### Или из папки src/game:
```bash
cd src/game
python PyGameBall.py
```

## Управление игрой

### Ручной режим:
- **←** и **→** - движение платформы
- **Enter** - запуск мяча
- **↑** и **↓** - изменение скорости мяча
- **M** - включение/отключение звука
- **H** - просмотр таблицы рекордов
- **R** - перезапуск игры (после окончания)
- **ESC** - выход из игры

### Авторежим:
- Нажмите **0** для запуска авторежима
- Игра будет играть автоматически с использованием AI
- **ESC** - выход из игры

## Решение проблем

### Ошибка "ModuleNotFoundError: No module named 'numpy'"
Установите numpy:
```bash
pip install numpy>=2.1.0
```

### Ошибка "ModuleNotFoundError: No module named 'pygame'"
Установите pygame:
```bash
pip install pygame>=2.5.2
```

### Игра не запускается
1. Проверьте версию Python: `python --version`
2. Переустановите зависимости: `pip install -r requirements.txt --force-reinstall`
3. Убедитесь, что запускаете игру из корневой папки проекта
