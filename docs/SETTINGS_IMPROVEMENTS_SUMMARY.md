### 2. Производительность (РЕКОМЕНДУЕТСЯ) ✅

#### ✅ Кэширование пути к файлу

- Глобальный кэш `_settings_file_path_cache`


#### ✅ Ленивая загрузка настроек

- Параметр `lazy_load` в конструкторе
- Загрузка при первом обращении к `settings` property

```python
def __init__(self, ..., lazy_load: bool = False, ...):
    self._loaded = not lazy_load
    # Загрузка только при необходимости
```

#### ✅ Оптимизация сохранения

- Флаг `_dirty` для отслеживания изменений
- Пропуск сохранения если данные не изменились
- Сравнение с существующим файлом перед сохранением

```python
if not self._dirty:
    logger.debug("Настройки не изменены, пропускаем сохранение")
    return
```

## 📊 Сравнение: До и После

### До:

```python
def __init__(self):
    self.settings = {"ball_speed": 8}
    self.load_settings()
    self.save_settings()  # Всегда сохраняет

resources_dir = os.path.join(game_dir, "resources")  # Небезопасно
```

### После:

```python
def __init__(self, settings_file=None, lazy_load=False, fs=None):
    self._settings = {...}
    self._loaded = not lazy_load
    self._dirty = False
    if not lazy_load:
        self.load_settings()

resources_dir = safe_join_path(game_dir, "resources")  # Безопасно
```
