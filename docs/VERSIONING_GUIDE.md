# Руководство по версионированию проекта Арканоид

## 📋 Обзор

Проект использует **централизованную систему версионирования** с форматом **X.Y.ZZZZ**:
- **X** - мажорная версия (революционные изменения)
- **Y** - минорная версия (новые функции, исправления UI)
- **ZZZZ** - 4-значный индекс сборки (увеличивается при каждом изменении)

## 🎯 Единственный источник истины

**Файл `version.py`** - это единственное место, где хранится версия проекта.

Все остальные файлы импортируют версию оттуда:
- `PyGameBall.py` - `from version import VERSION`
- `src/game/PyGameBall.py` - `from version import VERSION`
- Скрипты сборки - автоматически читают из `version.py`

## 📝 Как обновить версию

### При изменении файлов проекта:

1. **Откройте `version.py`**

2. **Увеличьте индекс сборки (ZZZZ)**:
   ```python
   # Было: VERSION = "2.2.0001"
   # Стало: VERSION = "2.2.0002"
   VERSION = "2.2.0002"
   VERSION_BUILD = 2  # Обновите и это число
   ```

3. **Обновите `changelog.md`**:
   ```markdown
   ## [2.2.0002] - 2025-12-06
   
   ### Изменения
   - Описание того, что было изменено
   ```

4. **Готово!** Все остальные файлы автоматически получат новую версию.

### При мажорных/минорных изменениях:

**Мажорная версия (X)** - революционные изменения:
```python
# Было: VERSION = "2.2.0001"
# Стало: VERSION = "3.0.0001"
VERSION = "3.0.0001"
VERSION_MAJOR = 3
VERSION_MINOR = 0
VERSION_BUILD = 1
```

**Минорная версия (Y)** - новые функции:
```python
# Было: VERSION = "2.2.0001"
# Стало: VERSION = "2.3.0001"
VERSION = "2.3.0001"
VERSION_MAJOR = 2
VERSION_MINOR = 3
VERSION_BUILD = 1
```

## 🔍 Где используется версия

### Автоматически обновляется:

- ✅ `PyGameBall.py` - импортирует из `version.py`
- ✅ `src/game/PyGameBall.py` - импортирует из `version.py`
- ✅ `scripts/build_exe.py` - читает из `version.py`
- ✅ `scripts/build_msi.py` - читает из `version.py`
- ✅ `scripts/create_msi.py` - читает из `version.py`

### Требует ручного обновления:

- ⚠️ `pyproject.toml` - формат Poetry (X.Y.Z без 4-значного индекса)
  ```toml
  version = "2.2.1"  # Poetry формат
  ```
  Обновляйте вручную при изменении мажорной/минорной версии.

- ⚠️ `README.MD` - бейдж версии
  ```markdown
  ![Версия](https://img.shields.io/badge/version-2.2.0002-blue.svg)
  ```
  Обновляйте вручную при изменении версии.

- ⚠️ `changelog.md` - записи об изменениях
  Обновляйте при каждом изменении версии.

## 📊 Примеры версий

| Изменение | Старая версия | Новая версия |
|-----------|---------------|--------------|
| Мелкое исправление | 2.2.0001 | 2.2.0002 |
| Новые функции | 2.2.0005 | 2.3.0001 |
| Революционные изменения | 2.2.0010 | 3.0.0001 |

## ✅ Чеклист при обновлении версии

- [ ] Обновлен `version.py` (VERSION и VERSION_BUILD)
- [ ] Обновлен `changelog.md` с описанием изменений
- [ ] Обновлен `README.MD` (бейдж версии)
- [ ] Обновлен `pyproject.toml` (если изменилась мажорная/минорная версия)
- [ ] Проверена работа скриптов сборки
