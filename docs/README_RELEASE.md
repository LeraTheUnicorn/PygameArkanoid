# Руководство по релизу игры Арканоид

## 🚀 Готовый исполняемый файл

### Arkanoid_v2.0.0.exe

**Размер:** ~30 МБ\
**Требования:** Windows 7/10/11 (64-bit)\
**Зависимости:** Включены (pygame 2.5+, numpy)

#### Использование:

1. Скачайте файл `Arkanoid_v2.0.0.exe`
1. Запустите двойным кликом
1. Игра готова к использованию без установки Python!

#### Особенности:

- ✅ Полностью переносимый - работает с любого места
- ✅ **Революционная AI-система** - авторежим по клавише "0"
- ✅ Система рекордов
- ✅ Не требует прав администратора
- ✅ Модульная архитектура с AI компонентами

## 🔧 Создание нового релиза

### Автоматический релиз

```bash
# Сборка исполняемого файла
python scripts/build_exe.py

# Сборка через спецификацию PyInstaller
python scripts/build_spec.py
```

### Обновленная структура сборки

**Ресурсы:** Все игровые ресурсы теперь находятся в корневой папке `game_resources/`:

- `game_resources/sounds/` - звуковые файлы
- `game_resources/images/` - изображения
- `game_resources/highscores.py` - система рекордов
- `game_resources/settings.py` - настройки игры
- `game_resources/settings.json` - конфигурация

**Скрипты сборки:**

- `scripts/build_exe.py` - основной скрипт сборки (обновлен)
- `scripts/build_spec.py` - альтернативный метод сборки (обновлен)

### Ручная сборка (с новой архитектурой)

```bash
# Очистка предыдущих сборок
rm -rf dist build *.spec

# Сборка с PyInstaller (обновленные пути к ресурсам)
pyinstaller --onefile --windowed --name Arkanoid_v2.0.0 ^
    --add-data "game_resources/sounds;sounds" ^
    --add-data "game_resources/images;images" ^
    --add-data "game_resources/highscores.py;." ^
    --add-data "game_resources/settings.py;." ^
    --add-data "game_resources/settings.json;." ^
    --hidden-import pygame ^
    --hidden-import numpy ^
    --exclude-module tkinter ^
    --exclude-module matplotlib ^
    --clean PyGameBall.py

# Копирование в папку FINAL_RELEASE
mkdir -p FINAL_RELEASE
cp dist/Arkanoid_v2.0.0.exe FINAL_RELEASE/
```

## 🎮 Функции игры

### Основной геймплей

- **Классический геймплей Арканоид** - отбивайте мяч платформой и разрушайте кубики
- **Система рекордов** - топ-10 лучших результатов с отсчетом времени
- **Управление скоростью** - клавиши ↑↓ для изменения скорости мяча в реальном времени

### 🤖 Революционная AI-система (v1.8+)

- **Авторежим** - нажмите "0" для запуска игры под управлением ИИ (имя "robot")
- **Предсказание траектории** - AI точно предсказывает траекторию мяча с учетом отскоков
- **Машинное обучение** - система учится на каждом действии и улучшается
- **Визуальная отладка** - отображение предсказанной траектории зелеными линиями
- **Аналитика производительности** - подробная статистика с сохранением в JSON

### Звуковые эффекты и интерфейс

- **Процедурная генерация звуков** - 16-битные тональные эффекты (440Гц, 523Гц, 659Гц)
- **Фоновая музыка** - управлением по клавише M
- **Полная локализация** - русский язык во всем интерфейсе
- **Цветные подсказки** - выделение ключевых клавиш желтым цветом
- **Индикатор авторежима** - визуальное отображение активного AI в HUD
