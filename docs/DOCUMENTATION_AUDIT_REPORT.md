## 📋 Система версионирования

### Формат версии: X.Y.ZZZZ
- **X** (2) - мажорная версия (революционные изменения)
- **Y** (2) - минорная версия (новые функции, исправления UI)
- **ZZZZ** (0002) - 4-значный индекс сборки (увеличивается при каждом изменении)

### Текущая версия: 2.2.0002

### Правило обновления версии:
**При каждом изменении файлов проекта:**
1. Увеличьте индекс сборки в `version.py` (ZZZZ)
2. Обновите `changelog.md` с описанием изменений
3. Обновите `README.MD` (бейдж версии)
4. Все остальные файлы автоматически получат новую версию
