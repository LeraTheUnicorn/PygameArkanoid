,# Руководство по созданию инсталлятора

## 📋 Обзор

Этот документ содержит инструкции по созданию инсталлятора для игры Арканоид. Инсталлятор позволяет пользователям легко устанавливать игру без необходимости вручную устанавливать зависимости.

## 📋 Создание инсталлятора

### 1. Установка зависимостей

1. **Установите Poetry**:
   ```bash
   pip install poetry
   ```

2. **Установите зависимости**:
   ```bash
   poetry install
   ```

### 2. Сборка исполняемого файла

1. **Соберите исполняемый файл**:
   ```bash
   python scripts/build_exe.py
   ```

2. **Соберите MSI инсталлятор**:
   ```bash
   python scripts/build_msi.py
   ```

### 3. Создание инсталлятора

1. **Создайте инсталлятор**:
   ```bash
   python scripts/create_installer.iss
   ```

2. **Создайте MSI инсталлятор**:
   ```bash
   python scripts/create_msi.py
   ```

### 4. Тестирование инсталлятора

1. **Запустите инсталлятор**:
   ```bash
   Arkanoid_v2.3.0.exe
   ```

2. **Проверьте установку**:
   ```bash
   python -m pip list | findstr pygame  # Windows
   python -m pip list | grep pygame     # Linux/Mac
   ```

### 5. Создание релиза

1. **Создайте новый релиз на GitHub**:
   - Укажите версию
   - Добавьте описание изменений
   - Прикрепите исполняемые файлы

2. **Обновите файл `docs/README_RELEASE.md`**:
   - Добавьте информацию о новом релизе
   - Укажите дату выпуска
   - Добавьте ссылки на загрузку
