# Условия перезапуска игры

## 📋 Обзор

В игре Arkanoid есть несколько сценариев, при которых происходит перезапуск игры. Этот документ описывает все условия и механизмы перезапуска.

---

## 🔄 Типы перезапуска

### 1. **Автоматический перезапуск в режиме обучения (Training Mode)**

#### 1.1. Перезапуск после победы (все кубики сбиты)
**Условия:**
- `training_mode = True`
- `bricks = []` (все кубики уничтожены)
- `game_over = True` устанавливается автоматически

**Что происходит:**
1. Сохраняется результат игры (победа)
2. AI обучается на результате (`learn_from_result`, `on_game_end`)
3. Сбрасываются все трекеры состояния AI (`_reset_game_state_trackers()`)
4. Создаются новые объекты: `Paddle()`, `Ball()`, `build_bricks()`
5. Восстанавливаются жизни: `lives_left = MAX_LIVES`
6. Сбрасывается счет: `score = 0`
7. Устанавливается оптимальная скорость мяча из обучения
8. Игра автоматически запускается: `game_started = True`

**Местоположение в коде:**
- `src/game/PyGameBall.py`, строки **2792-2855** (первый блок)
- `src/game/PyGameBall.py`, строки **3053-3134** (второй блок)

---

#### 1.2. Перезапуск после потери всех жизней
**Условия:**
- `training_mode = True`
- `lives_left <= 0` (все жизни потрачены)
- `game_over = True` устанавливается при потере последней жизни

**Что происходит:**
1. Рассчитывается время игры и количество уничтоженных кубиков
2. Сохраняется результат игры (поражение)
3. AI обучается на результате (`learn_from_result`, `on_game_end`)
4. Сбрасываются все трекеры состояния AI (`_reset_game_state_trackers()`)
5. Создаются новые объекты: `Paddle()`, `Ball()`, `build_bricks()`
6. Восстанавливаются жизни: `lives_left = MAX_LIVES`
7. Сбрасывается счет: `score = 0`
8. Устанавливается оптимальная скорость мяча из обучения
9. Игра автоматически запускается: `game_started = True`

**Местоположение в коде:**
- `src/game/PyGameBall.py`, строки **2135-2206** (первый блок)
- `src/game/PyGameBall.py`, строки **2553-2634** (второй блок)
- `src/game/PyGameBall.py`, строки **2875-2956** (третий блок)

---

### 2. **Ручной перезапуск (Manual Mode)**

#### 2.1. Перезапуск клавишей R
**Условия:**
- `game_over = True` (игра окончена)
- Нажата клавиша `pygame.K_r` (клавиша R)
- Режим: **НЕ** training_mode (ручной режим)

**Что происходит:**
1. Создаются новые объекты: `Paddle()`, `Ball()`
2. Устанавливается скорость мяча из настроек
3. Сбрасывается мяч на платформу
4. Создаются новые кубики: `build_bricks()`
5. Сбрасывается счет: `score = 0`
6. Восстанавливаются жизни: `lives_left = MAX_LIVES`
7. Игра **НЕ** запускается автоматически: `game_started = False`
8. Пользователь должен нажать стрелку для старта

**Местоположение в коде:**
- `src/game/PyGameBall.py`, строки **1708-1727**

---

#### 2.2. Перезапуск через экран результатов
**Условия:**
- `game_over = True` (игра окончена)
- Пользователь выбрал "Перезапустить" на экране результатов
- Функция `show_game_results()` вернула `restart_game = True`

**Что происходит:**
1. Создаются новые объекты: `Paddle()`, `Ball()`
2. Устанавливается скорость мяча из настроек
3. Сбрасывается мяч на платформу
4. Создаются новые кубики: `build_bricks()`
5. Сбрасывается счет: `score = 0`
6. Восстанавливаются жизни: `lives_left = MAX_LIVES`
7. Игра **НЕ** запускается автоматически: `game_started = False`
8. Создается новый экземпляр `AIPlayer` (если используется AI)

**Местоположение в коде:**
- `src/game/PyGameBall.py`, строки **1663-1684**
- `src/game/PyGameBall.py`, строки **2686-2712** (ручной режим)
- `src/game/PyGameBall.py`, строки **3008-3034** (ручной режим)
- `src/game/PyGameBall.py`, строки **3181-3205** (ручной режим)

---

### 3. **Сброс целевой позиции AI (НЕ перезапуск игры)**

#### 3.1. Нарушение правила фиксации позиции
**Условия:**
- `ai_player.separation_zone_tracker.game_restart_required = True`
- Это происходит, когда система пытается установить **другую** целевую позицию, 
  когда позиция уже зафиксирована (разница > 5px)

**Что происходит:**
- **НЕ перезапускается игра!**
- Только сбрасывается целевая позиция AI:
  - `target_position_set = False`
  - `target_position = None`
- Устанавливается новая целевая позиция
- Флаг `game_restart_required` сбрасывается в `False`

**Местоположение в коде:**
- `src/game/PyGameBall.py`, строки **1742-1755**
- `src/ai/strategy/target_tracker.py`, строки **42-75**

**Важно:** Это **НЕ** перезапуск игры, а только сброс состояния AI для корректной работы алгоритма движения платформы.

---

## 🔍 Детали механизма

### Когда НЕ происходит перезапуск:

1. **При потере одной жизни** (но не всех)
   - Игра продолжается, мяч сбрасывается на платформу
   - Перезапуск происходит только при `lives_left <= 0`

2. **При нарушении правила фиксации позиции**
   - Только сбрасывается целевая позиция AI
   - Игра продолжается нормально

3. **В авторежиме (auto_mode) без training_mode**
   - Игра не перезапускается автоматически
   - Пользователь должен перезапустить вручную

## 🛠️ Технические детали

### Функции, участвующие в перезапуске:

1. **`_reset_game_state_trackers()`** - сбрасывает все трекеры состояния AI
2. **`learn_from_result()`** - обучает AI на результате игры
3. **`on_game_end()`** - обрабатывает окончание игры
4. **`update_game_state()`** - обновляет состояние игры для AI после перезапуска
5. **`get_optimal_ball_speed()`** - получает оптимальную скорость мяча из обучения

### Переменные, которые сбрасываются:

- `paddle` - новый объект `Paddle()`
- `ball` - новый объект `Ball()`
- `bricks` - новый список кубиков `build_bricks()`
- `score = 0`
- `lives_left = MAX_LIVES`
- `game_over = False`
- `game_start_time = time.time()`
- Все трекеры AI (`_reset_game_state_trackers()`)

---

## ⚠️ Важные замечания

1. **В режиме обучения** игра перезапускается автоматически после каждой игры (победа или поражение)
2. **В ручном режиме** игра не перезапускается автоматически - пользователь должен нажать R или выбрать перезапуск на экране результатов
3. **Нарушение правила фиксации позиции** НЕ вызывает перезапуск игры - это исправлено для предотвращения зависаний
4. После перезапуска в режиме обучения AI сразу получает обновленное состояние игры через `update_game_state()`

## 📝 Логирование

Все перезапуски логируются с префиксом `[GAME RESTART]`:
- `[GAME RESTART] Игра успешно перезапущена!`
- `[GAME RESTART] Начинаем перезапуск игры в режиме обучения...`
- `[GAME RESTART] Игра перезапущена после потери всех жизней!`
- `[GAME RESTART ERROR]` - ошибки при перезапуске

События также логируются в `performance_logger`:
- `GAME_RESTART_AFTER_WIN` - перезапуск после победы
- `GAME_RESTART_AFTER_LOSS` - перезапуск после поражения
