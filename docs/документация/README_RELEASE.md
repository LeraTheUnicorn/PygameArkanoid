# Руководство по выпуску версии

## 📋 Процесс выпуска новой версии

### 1. Обновление версии

1. **Обновите файл `version.py`**:
   ```python
   VERSION_MAJOR = 2
   VERSION_MINOR = 3
   VERSION_BUILD = 0
   ```

2. **Обновите файл `pyproject.toml`**:
   ```toml
   [tool.poetry]
   name = "arkanoid-game"
   version = "2.3.0"  # Poetry формат: X.Y.Z (соответствует version.py: VERSION_MAJOR=2, VERSION_MINOR=3, VERSION_BUILD=0)
   ```

### 2. Обновление документации

1. **Обновите файл `README.MD`**:
   - Обновите версию в заголовке
   - Добавьте описание новых функций
   - Обновите раздел "Установка и запуск"

2. **Обновите файл `docs/changelog.md`**:
   - Добавьте новый раздел с версией
   - Опишите все изменения и улучшения
   - Укажите дату выпуска

3. **Обновите файл `docs/AI_ARCHITECTURE.md`**:
   - Добавьте описание новых функций AI
   - Обновите раздел "Файловая структура"

4. **Обновите файл `docs/AI_ISSUES_AND_SOLUTIONS.md`**:
   - Добавьте описание решений новых проблем
   - Обновите раздел "Реализованные исправления"

5. **Обновите файл `docs/INSTALL_GUIDE.md`**:
   - Добавьте информацию о новых зависимостях
   - Обновите раздел "Список зависимостей"

### 3. Обновление зависимостей

1. **Обновите файл `pyproject.toml`**:
   - Добавьте новые зависимости
   - Обновите версии существующих зависимостей

2. **Обновите файл `poetry.lock`**:
   ```bash
   poetry lock
   ```

### 4. Сборка и тестирование

1. **Соберите исполняемый файл**:
   ```bash
   python scripts/build_exe.py
   ```

2. **Соберите MSI инсталлятор**:
   ```bash
   python scripts/build_msi.py
   ```

3. **Запустите тесты**:
   ```bash
   poetry run pytest
   ```

### 5. Создание релиза

1. **Создайте новый релиз на GitHub**:
   - Укажите версию
   - Добавьте описание изменений
   - Прикрепите исполняемые файлы

2. **Обновите файл `docs/README_RELEASE.md`**:
   - Добавьте информацию о новом релизе
   - Укажите дату выпуска
   - Добавьте ссылки на загрузку
