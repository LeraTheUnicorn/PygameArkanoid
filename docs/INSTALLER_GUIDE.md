# Руководство по созданию инсталляторов для игры Арканоид

## 📦 Готовые инсталляторы

### Текущий статус:
- ✅ **Arkanoid_v2.0.0.exe** - готовый исполняемый файл (30 МБ)
- ✅ **Arkanoid_v2.0.0_Setup.exe** - EXE инсталлятор (требует Inno Setup)
- ✅ **Arkanoid_v2.0.0_Setup.msi** - MSI инсталлятор (требует WiX Toolset)
- 🆕 **AI-система** - революционная система авторежима в v2.0+

## 🛠️ Необходимые инструменты

### 1. Inno Setup (для EXE инсталлятора)
**Скачать:** https://jrsoftware.org/isinfo.php

**Функции:**
- Создание EXE инсталляторов
- Создание ярлыков на рабочем столе
- Интеграция с системой Windows
- Поддержка нескольких языков

**Установка:**
1. Скачайте Inno Setup с официального сайта
2. Установите в стандартную директорию
3. Перезапустите командную строку

### 2. WiX Toolset (для MSI инсталлятора)
**Скачать:** https://github.com/wixtoolset/wix/releases/

**Функции:**
- Создание MSI пакетов
- Глубокая интеграция с Windows Installer
- Поддержка групповых политик
- Профессиональное распространение ПО

**Установка:**
1. Скачайте WiX v6.0 или новее с https://github.com/wixtoolset/wix/releases/
2. Установите и добавьте в PATH:
   ```
   C:\Program Files\WiX Toolset v6.0\bin
   ```
   (или актуальный на момент установки)

3. Или используйте Chocolatey: `choco install wixtoolset`

## 🚀 Способы создания инсталляторов

### Способ 1: Автоматический (рекомендуется)
```bash
# Сборка исполняемого файла
python scripts/build_exe.py

# Сборка MSI инсталлятора
python scripts/build_msi.py
```

### Способ 2: Ручной - EXE инсталлятор
```bash
# 1. Соберите исполняемый файл
python scripts/build_exe.py

# 2. Скомпилируйте инсталлятор
scripts/compile_installer.bat
```

### Способ 3: Ручной - MSI инсталлятор
```bash
# Убедитесь, что WiX установлен и добавлен в PATH
python scripts/create_msi.py
```

### Способ 4: Альтернативная сборка
```bash
# Использование спецификации PyInstaller
python scripts/build_spec.py
```

## 🔧 Настройка инсталляторов

### EXE инсталлятор (Inno Setup)
**Локация установки:** `%LOCALAPPDATA%\Games\Arkanoid`

**Функции:**
- ✅ Создание ярлыка на рабочем столе
- ✅ Создание ярлыка в меню "Пуск"
- ✅ Создание папки для рекордов
- ✅ Корректная деинсталляция
- ✅ Поддержка русского и английского языков

### MSI инсталлятор (WiX)
**Локация установки:** `%LOCALAPPDATA%\Games\Arkanoid`

**Функции:**
- ✅ Полная интеграция с Windows Installer
- ✅ Создание ярлыка на рабочем столе
- ✅ Регистрация в системе (Programs and Features)
- ✅ Поддержка групповых политик
- ✅ Возможность автоматической установки
- ✅ Создание папки для рекордов

## 🎮 Особенности игры в инсталляторе

### Система рекордов
- **Локация файла:** `%LOCALAPPDATA%\Games\Arkanoid\highscores.json`
- **Автоматическое создание:** Папка и файл создаются при первом запуске
- **Переносимость:** Рекорды сохраняются при переустановке игры

### Пути к ресурсам
- **Звуки:** `%LOCALAPPDATA%\Games\Arkanoid\sounds\`
- **Изображения:** `%LOCALAPPDATA%\Games\Arkanoid\images\`
- **Исполняемый файл:** `%LOCALAPPDATA%\Games\Arkanoid\Arkanoid_v1.6.1.exe`

## 🧪 Тестирование инсталляторов

### Проверка EXE инсталлятора:
1. Запустите `Arkanoid_v1.6.1_Setup.exe`
2. Пройдите процесс установки
3. Проверьте наличие ярлыков
4. Запустите игру
5. Проверьте создание файла рекордов

### Проверка MSI инсталлятора:
1. Установите: `msiexec /i Arkanoid_v1.6.1_Setup.msi`
2. Проверьте в "Programs and Features"
3. Запустите игру через ярлык
4. Проверьте деинсталляцию: `msiexec /x Arkanoid_v1.6.1_Setup.msi`

## 🔍 Устранение неполадок

### Inno Setup не найден:
```
ERROR: Inno Setup Compiler не найден в PATH
```
**Решение:** Установите Inno Setup и перезапустите командную строку

### WiX Toolset не найден:
```
WiX Toolset не найден!
```
**Решение:** Установите WiX v6.0 и добавьте в PATH:
```bash
set PATH=%PATH%;C:\Program Files\WiX Toolset v6.0\bin
```

### Ошибка создания иконки:
```
PIL (Pillow) не установлен
```
**Решение:** `pip install Pillow`
