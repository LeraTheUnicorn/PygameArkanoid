# Архитектура AI-системы для авторежима игры Арканоид

## Обзор системы

Система машинного обучения для улучшения авторежима, которая анализирует траекторию мяча и принимает оптимальные решения о позиционировании платформы.

## Компоненты системы

### 1. AIPlayer (Основной класс)

```python
class AIPlayer:
    - trajectory_predictor: TrajectoryPredictor
    - position_optimizer: PositionOptimizer  
    - learning_system: LearningSystem
    - performance_logger: PerformanceLogger
    - game_state: GameState
    - targeting_system: dict  # Система прицельного отбивания
    - loop_prevention_system: dict  # Система предотвращения зацикливания
```

### 2. TrajectoryPredictor (Предсказание траектории)

- Рассчитывает траекторию мяча в разделительной зоне
- Определяет точку пересечения с платформой
- Предсказывает траекторию после отскока

### 3. PositionOptimizer (Оптимизация позиции)

- Находит оптимальное положение платформы
- Рассчитывает угол отскока для попадания в целевые кубики
- Использует физические принципы отражения

### 4. LearningSystem (Система обучения)

- Логирует все действия и результаты
- Анализирует эффективность стратегий
- Корректирует алгоритм на основе результатов
- Сохраняет обученные модели

### 5. PerformanceLogger (Логирование производительности)

- Записывает все ходы и результаты
- Сохраняет в JSON файл для анализа
- Генерирует статистику улучшений
- Кастомный JSON encoder для Point и pygame.Rect объектов

### 6. Система прицельного отбивания (TargetingSystem)

- **Карта координат кубиков** - динамическое обновление позиций всех кубиков на поле
- **Видимые цели** - анализ траектории мяча для определения достижимых кубиков
- **Специальная логика для малого количества кубиков** - приоритет завершения уровня при ≤5 кубиках
- Поиск лучших целевых кубиков для прицеливания с учетом видимости
- Расчет оптимального смещения на платформе (-1 до 1)
- Ведение истории успешных ударов с паттернами попаданий
- Корректировка стратегии на основе исторических данных
- Предотвращение вертикальных ударов при малом смещении

### 7. Система предотвращения зацикливания (LoopPreventionSystem)

- **Усиленная детекция** - порог повторений 80% (вместо 60%)
- **Позиционная стагнация** - обнаружение неподвижности платформы
- **Вертикальные траектории** - предотвращение симметричных паттернов
- Обнаружение повторяющихся паттернов движений
- Автоматическая смена стратегии при зацикливании
- Альтернативные стратегии: center_focus, edge_focus, predictive_targeting
- Переоценка позиций после каждого отбития мяча
- Кулдаун смены стратегии (10 кадров)

### 8. Система отскоков от потолка (CeilingBounceSystem)

- Специальная логика позиционирования при отскоках от потолка
- Предотвращение симметричных вертикальных ударов
- Анализ направления движения мяча после отскока
- Позиционирование относительно оставшихся кубиков
- Случайные смещения для разрушения паттернов

## Алгоритм работы

### Этап 1: Анализ состояния и обновление карты

1. Определить текущее состояние игры:
    - Позиция мяча и скорость
    - Оставшиеся кубики и их координаты
    - Позиция платформы
1. **Обновить карту кубиков** - создать brick_map с координатами центров
1. **Определить видимые цели** - рассчитать траектории для различных позиций платформы

### Этап 2: Предсказание траектории и анализ отскоков

1. Рассчитать траекторию падения мяча с учетом отскоков от стен
1. Определить точки возможных отскоков от платформы
1. Предсказать траекторию после отскока
1. **Проверить отскок от потолка** - специальная логика при ball_y < 50

### Этап 3: Интеллектуальный выбор цели и прицеливание

1. **Приоритизировать видимые цели** - кубики, достижимые текущей траекторией
1. **Специальная логика для малого количества кубиков** (≤5):
    - Максимальный приоритет нижним кубикам
    - Фокус на завершении уровня
1. Для каждого целевого кубика рассчитать:
    - Необходимый угол отскока
    - Требуемую точку попадания на платформе
1. Выбрать лучший целевой кубик с учетом:
    - Видимости траектории
    - Расстояния до платформы
    - Исторических успехов
1. Рассчитать оптимальное смещение на платформе (-1 до 1)
1. **Предотвратить вертикальные удары** - добавить случайное смещение при малом delta_x

### Этап 4: Усиленная проверка зацикливания

1. Проанализировать историю движений платформы
1. **Обнаружить повторяющиеся паттерны (80% повторений)**
1. **Проверить позиционную стагнацию** - неподвижность платформы
1. **Анализ вертикальных траекторий** - 4 из 5 последних траекторий
1. При необходимости сменить стратегию с кулдауном 10 кадров

### Этап 5: Точное позиционирование платформы

1. Рассчитать путь к целевой позиции с учетом смещения
1. **Строго ограничивать границы** - запас 5 пикселей от краев экрана
1. Двигаться к позиции с высокой точностью (допуск 2 пикселя)
1. Корректировать позицию при изменении траектории

### Этап 6: Обучение и переоценка после отбития

1. Оценить результат хода и записать в историю попаданий
1. **Переоценить ситуацию после отбития** - обновить цели и смещения
1. Обновить модель на основе успешности
1. Сохранить данные для будущего анализа
1. **Очистить историю зацикливания** для нового цикла

## Математические модели

### Предсказание траектории мяча

```
x(t) = x0 + vx * t
y(t) = y0 + vy * t + 0.5 * g * t^2

где:
- (x0, y0) - начальная позиция
- (vx, vy) - начальная скорость
- g - ускорение свободного падения
- t - время
```

### Расчет отскока от платформы

```
Новый угол = arctan(|vy/vx|)
Новая скорость = скорость * коэффициент отскока
```

### Оптимизация позиции платформы

```
Функция оценки = Σ(w_i * P(попадание в кубик i))

где:
- w_i - вес кубика i (количество очков)
- P(попадание) - вероятность попадания в кубик
```

### Кастомный JSON Encoder

```
Point сериализация:
{"x": 100, "y": 200}

pygame.Rect сериализация:
{"x": 50, "y": 75, "width": 120, "height": 25, "centerx": 110, "centery": 87}
```
