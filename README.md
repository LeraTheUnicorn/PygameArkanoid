# 🕹️ Игра Арканоид с AI-системой

Классическая игра Арканоид, написанная на Python с использованием Pygame. Включает в себя систему рекордов, звуковые
эффекты и современный интерфейс.

![Версия](https://img.shields.io/badge/version-2.1.0-blue.svg)
![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
![Pygame](https://img.shields.io/badge/pygame-2.5+-green.svg)

## 🎮 Особенности

### Геймплей

- **Классический геймплей Арканоид** - отбивайте мяч платформой и разрушайте кубики

### ИИ-система (AI)

- **Авторежим игры** - нажмите "0" для запуска интеллектуального авторежима с именем "robot"
- **Предсказание траектории** - ИИ точно предсказывает траекторию мяча с учетом отскоков от стен
- **Машинное обучение** - система учится на каждом действии и улучшает производительность
- **Визуальная отладка** - отображение предсказанной траектории и оптимальных позиций
- **Система аналитики** - подробная статистика производительности ИИ с сохранением в JSON
- **Интеллектуальное управление** - оптимальное позиционирование платформы для максимальной эффективности

### Система рекордов

- **Подсчет очков** - подсчет очков для каждой игры
- **Отсчет времени** - точное время прохождения каждой игры
- **Топ-10 таблица** - сохранение лучших результатов

### Звуковые эффекты

- **Процедурная генерация звуков** - 16-битные тональные эффекты
- **Фоновая музыка** - для настроения
- **Звуки разрушения** - разные частоты для разных ситуаций

### Интерфейс

- **Полная локализация** - русский язык во всем интерфейсе
- **Контекстные подсказки** - цветное выделение ключевых клавиш (Enter, H, M, ESC)
- **Гибкая навигация** - ESC и крестик для выхода, Backspace для возврата
- **Просмотр рекордов** - по клавише H в любом месте игры
- **Подробная статистика** - очки, время, количество отбитий
- **Отображение скорости** - текущая скорость мяча в правом верхнем углу
- **Управление скоростью** - кнопки ↑/↓ для изменения скорости в реальном времени
- **Экран результатов** - детальная информация по завершении

## 🤖 ИИ-система (Machine Learning)

### Архитектура AI

В проекте используется **комплексная система машинного обучения**, основанная на **проприетарном Reinforcement Learning (RL) алгоритме** и **физических моделях предсказания траекторий**.

**Основные компоненты:**
1. **AIPlayer** - главный оркестратор системы
2. **TrajectoryPredictor** - предсказание траекторий мяча  
3. **PositionOptimizer** - оптимизация позиции платформы
4. **LearningSystem** - система обучения с подкреплением
5. **PerformanceLogger** - логирование и анализ производительности

### Алгоритм машинного обучения

**Тип модели:** 
- **Custom Reinforcement Learning** (обучение с подкреплением)
- **Проприетарная реализация** на основе эвристического подхода
- **НЕ использует** TensorFlow, PyTorch или scikit-learn

**Ключевые особенности:**
- Адаптивные веса стратегий: `aggressive`, `conservative`, `precision`, `speed`
- Анализ паттернов траекторий с квантованием координат
- Система предотвращения зацикливания (loop prevention)
- Обучение на основе успешности действий

### Математические модели

**1. Предсказание траектории:**
```
x(t) = x0 + vx * t
y(t) = y0 + vy * t + 0.5 * g * t^2
```

**2. Оптимизация позиции:**
```
Функция оценки = Σ(w_i * P(попадание в кубик i))
```

**3. Отражение от платформы:**
```
Новый угол = arctan(|vy/vx|)
Новая скорость = скорость * коэффициент отскока
```

### Обученная модель

**Файл модели:** `ai/models/ai_model.json`

**Статистика обучения:**
- **1,873 итерации обучения**
- **99.67% успешных адаптаций** (1,866 успешных из 1,873)
- **4 типа стратегий** с динамическими весами

**Текущие веса стратегий:**
```json
{
  "aggressive": 0.5,
  "conservative": 1.0,
  "precision": 0.975,
  "speed": 1.0
}
```

### Алгоритмы принятия решений

**1. Анализ ситуации:**
- Предсказание траектории мяча
- Поиск оптимальных целевых кубиков
- Расчет требуемого угла отскока

**2. Система прицеливания:**
- Поиск лучших целевых кубиков
- Расчет оптимального смещения на платформе
- История успешных ударов

**3. Предотвращение зацикливания:**
- Обнаружение повторяющихся паттернов (60% повторений)
- Автоматическая смена стратегии
- Альтернативные стратегии: `center_focus`, `edge_focus`, `predictive_targeting`

### Производительность системы

**Критерии успеха:**
- **20-30% улучшение** скорости прохождения vs базовый авторежим
- **Уменьшение "случайных" отскоков**
- **Больше целенаправленных попаданий**
- **Постоянное улучшение с опытом**

**Логирование:**
- JSON-файлы с детальной статистикой
- Анализ точности предсказаний траекторий
- Отслеживание прогресса обучения

### Режимы работы AI

**Debug Mode:**
- Детальная визуализация предсказанных траекторий
- Отображение оптимальных позиций платформы
- Логирование всех решений AI

**Production Mode:**
- Оптимизированная производительность без визуализации
- Скрытая отладка и аналитика
- Фокус на скорости принятия решений

### Автоматическое обучение

**Особенности:**
- Система сохраняет прогресс между сессиями
- Адаптивная корректировка стратегий в реальном времени
- Персистентное хранение в `ai/models/ai_model.json`
- Анализ факторов успеха: скорость мяча, расстояние платформы, количество кубиков

**Уникальность системы:** Это **гибридная система**, сочетающая физическое моделирование траекторий с адаптивными алгоритмами обучения, оптимизированная специально для игровой механики Арканоид.

### Как запустить AI

1. **Запустите игру**
2. **Нажмите "0"** для активации авторежима
3. **AI автоматически примет управление** под именем "robot"
4. **Для отладки:** включите debug режим в настройках для визуализации

## 🚀 Установка и запуск

### Вариант 1: Готовый исполняемый файл (рекомендуется)

**Скачайте готовый файл:** `FINAL_RELEASE/Arkanoid_v2.0.0.exe`

- **Размер:** ~30 МБ
- **Требования:** Windows 7/10/11 (64-bit)
- **Установка:** Не требуется, просто запустите файл
- **Переносимость:** Работает с любого места

### Вариант 2: Инсталлятор

**EXE инсталлятор:** `FINAL_RELEASE/Arkanoid_v2.0.0_Setup.exe`

- Автоматическая установка в `%LOCALAPPDATA%\Games\Arkanoid`
- Создание ярлыков на рабочем столе и в меню "Пуск"
- Профессиональный установщик с поддержкой русского языка

**MSI инсталлятор:** `FINAL_RELEASE/Arkanoid_v2.0.0_Setup.msi`

- Профессиональный пакет Windows Installer
- Поддержка групповых политик
- Корпоративное развертывание

### Вариант 3: Запуск из исходного кода

#### Требования

- Python 3.8 или выше
- Poetry (рекомендуется) или pip

#### С Poetry (рекомендуется)

```bash
# Клонирование репозитория
git clone <repository-url>
cd PythonProject2

# Установка зависимостей
poetry install

# Запуск игры
poetry run python PyGameBall.py

# Или активация окружения
poetry shell
python PyGameBall.py
```

#### С pip

```bash
# Установка зависимостей
pip install pygame numpy

# Запуск игры
python PyGameBall.py
```

## 🎵 Звуковая система

### Процедурная генерация звуков

- **Частоты:** 440Гц, 523Гц, 659Гц (ноты A4, C5, E5)
- **Длительность:** 0.2 секунды с экспоненциальным затуханием
- **Формат:** 16-битный стерео, 44.1 кГц
- **Гармоники:** дополнительные частоты для богатого звучания

## 🏆 Система рекордов

### Сортировка результатов

1. **По очкам** (по убыванию)
1. **При равных очках** - по времени игры (по возрастанию)
1. **При равных очках и времени** - по имени (алфавитный порядок)

### Сохранение данных

```json
{
  "player_name": "Игрок",
  "score": 42,
  "time_seconds": 85,
  "time_formatted": "1:25",
  "date": "2025-11-28 13:17"
}
```

## 🔧 Технические детали

### Зависимости
